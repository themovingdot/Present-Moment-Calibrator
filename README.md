# 当下刻度 | Present Moment Calibrator

> 把你的咒语做成一个随时可以"校准"自己的工具

一个精密的意识校准仪器。简洁、工程感、专注当下。

## 核心机制

- **智能提醒**：根据你的使用pattern，智能推荐最需要的咒语
- **意识记录**：每次校准都被记录，形成你的awareness pattern map
- **自由生长**：使用频率影响内容呈现，让工具成长为专属于你的形态

## 功能特性

### 三种校准模式

1. **类别选择**：觉察、放下、接纳、质疑、链接、行动、休息、视角
2. **随机唤醒**：让系统为你选择此刻最需要的提醒
3. **Pattern分析**：查看你的意识活动pattern，了解自己的节奏

### 自适应算法

- 使用越少的内容，被推荐的概率越高
- 避免总是看到相同的提醒
- 随着使用形成个性化的校准系统

### 数据追踪

- 记录每次calibration的时间和类别
- 分析24小时活动pattern
- 统计类别偏好和使用频率
- 所有数据存储在本地，完全私密

## 设计理念

### 精密仪器美学

- Monospace字体，工程感界面

- 实时时间戳显示

### 极简交互

## 快速开始

```bash
# 安装依赖
npm install

# 启动开发服务器
npm run dev

# 构建生产版本
npm run build
```

## 使用方法

1. **选择类别**：点击任意类别按钮，查看相应的咒语
2. **随机唤醒**：让系统根据你的使用pattern推荐内容
3. **完成校准**：阅读完毕后点击Complete，记录这次calibration
4. **查看Pattern**：点击View Pattern查看你的意识活动地图

## 自定义咒语

编辑 `src/data/mantras.ts` 文件，添加你自己的咒语：

```typescript
{
  id: 'custom001',
  category: '你的类别',
  content: '你的咒语内容\n可以多行',
  tags: ['tag1', 'tag2'],
}
```

## Pattern洞察

系统会追踪：

- **类别偏好**：你最常使用哪类提醒
- **时间pattern**：一天中什么时候最需要校准
- **使用频率**：平均每天校准多少次
- **个性化推荐**：基于历史自动调整推荐权重

## 隐私说明

所有数据都存储在浏览器本地（LocalStorage），不会上传到任何服务器。

清除数据：在浏览器控制台执行：
```javascript
localStorage.clear()
```

## 哲学

这不是一个提醒工具，而是一面镜子。

它不告诉你"应该"怎样，而是帮你看见此刻的需要。

随着使用，它会成长为专属于你的工具。
